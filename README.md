# The Jam 🍓

A beautiful, deliberately addictive incremental game inspired by the classic *Universal Paperclips* progression loop — but with its own jam-themed economy, automation, upgrades, market pressure, and increasingly ridiculous scale.

## Play

Open `index.html` in a browser. No build step, dependencies, or server required.

## Core loop

- Stir jars manually to get the economy moving.
- Balance berries, jars, demand, price, and cash.
- Unlock increasingly strange production ideas.
- Automate production and watch the numbers climb.
- Push from a tiny kitchen toward a cosmic jam operation.
- Progress persists in localStorage.

## Files

- `index.html` — interface and game shell
- `style.css` — visual design, responsive layout, animations
- `game.js` — simulation, progression, upgrades, persistence
